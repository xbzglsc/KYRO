# KYRO · 一眼洞悉，万语千言

单文件 HTML 实现的 AI 对话客户端。

## 直接使用

| 版本 | 地址 |
| --- | --- |
| **网页版（在线使用）** | https://xbzglsc.github.io/KYRO/ |
| 宣传演示（自动播放 ≈100s） | https://xbzglsc.github.io/KYRO/kyro-promo.html |

> 网页版无需安装，打开即用；聊天记录保存在本地浏览器。
> 支持 5 种语言：简体中文 · 繁體中文 · English · 日本語 · 한국어
